# Retail Sales Analysis
Exploratory data analysis of retail sales data (2015-2018) using Python.
## Overview
Analyzed sales trends across years, product catagories, customer segments and regions to identify key revenue drivers.
## Tech Stack
- Python
- Pandas, Matplotlib, Seaborn
- Jupyter Notebook
## Key Findings
- **Sales Trend:** Steady year-over-year revenue growth from 2015 to 2018.
- **Top Catagory:** Technology drove the highest total sales, followed by Furniture and Office Supplies.
- **Top Regions:** The West and East regions led overall transaction volume.
## Project Structure
- 'retail_sales_analysis.ipynb' - Data cleaning, analysis and visualizations.
- 'train.csv' - Raw transaction dataset.
